\# PlaywrightWebAutomation



Basic Playwright web automation.



Automated end-to-end test suite for QA Playground's SecureBank demo application, built with Playwright and TypeScript.



\## Tests Covered

\- Login (valid credentials, title verification)

\- Account management (add account, dynamic naming)

\- Transfers between accounts

\- Send Money to external payees

\- Bill Pay

\- Apply for a Loan

\- Transactions (search, filter, CSV download)

\- Notifications (mark read, mark all read)



\## Running Tests



npx playwright test



\## Project Structure

\- `tests/` — all test specs and shared fixtures

\- `playwright.config.ts` — Playwright configuration
